# BenefitTrack social studio

Everything needed to make BenefitTrack's Instagram posts in the house style.

- `RUNBOOK.md`: the weekly routine (make, check, upload, schedule).
- `STYLE.md`, `CONTENT.md`, `TOPICS.md`: look, approved facts and topic backlog.
- `templates/examples/`: the launch designs as HTML (render with `tools/render_png.js`).
- `films/`: the two launch animated reels as scene code (render with `reel/render.js`).
- `reel/`: the reel runtime, frame renderer and soundtrack generator.
- `assets/`: Geist fonts (SIL Open Font License), shield logo, blueprint backgrounds.

Files under `media/` are the published post files that Buffer pulls in. Only finished,
public post media belongs in this repository.
